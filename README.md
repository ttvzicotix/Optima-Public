# Project OPTIMA — Public Lab

> **Working codename.** Final product/company naming is intentionally undecided.

This repository is the deliberately public side of Project OPTIMA, an exploration of visual operations research and decision intelligence.

The private `Optima-Core` repository is the source of truth for production and potentially proprietary implementation. This repository is **not** intended to mirror Core.

## Planned public content

As the project matures, this repository may contain:

- synthetic datasets
- educational optimization examples
- visual demonstrations
- mathematical explanations
- reproducible sample scenarios
- public documentation
- eventual SDK/API examples
- components intentionally selected for open-source release

## First area of exploration: LOCATE

LOCATE explores facility-location decisions such as:

- minimizing weighted total distance/cost
- minimizing worst-case distance
- maximizing demand coverage within a service threshold

The goal is to make differences between these definitions of "best" visible and understandable.
